# 南方コレクター v3.0 — 探索精度強化仕様

更新日: 2026-10-08
状態: 設計仕様（実装・一次資料300件の調査は未完了）

## 目的と独立性
南方コレクターは PRINCIPLE LOOP の独立選択式モジュール。固定パイプラインには接続しない。基本原則「絞らない。遠くまで集める。」を維持し、採点・選抜・実現可能性による候補削除を行わない。林フィルター、JIMA FILTER の判断を内部に混入させない。

## v3.0 の探索操作
1. **距離探索**: 元テーマとの意味・機構・用途・時代・スケールの距離を変え、近距離／中距離／遠距離／極遠距離を並行収集する。遠距離候補を珍しさだけで高評価しない。
2. **関係の型を収集**: 類似、因果、循環、対立、媒介、相互依存、変換、制約、寄生、共生、時間差、情報の非対称を明示する。
3. **萃点を探す**: 事例を点、関係を辺とする多層ネットワークを作り、異分野・異種の関係が交差する箇所を候補として記録する。萃点は証明済みの原理と同一視しない。
4. **例外・矛盾を集める**: 成立しない条件、逆転する条件、反例、対立する説明を残す。削除せず別の探索起点にする。
5. **連鎖探索**: 発見した関係／萃点／例外を新たな種として次の探索へ。探索履歴と元テーマからの経路を保存し、人間が継続・停止を選択する。

## 出力スキーマ（提案）
各候補に id, seed, domain, observation, mechanism, relation_types[], source_refs[], evidence_level, contradiction_refs[], exploration_path[], distance_axes[], next_questions[] を持たせる。
萃点には constituent_ids[], intersecting_relation_types[], cross_domain_explanation, competing_explanations[], unexplored_branches[] を持たせる。
evidence_level は「一次資料で確認」「二次資料による解釈」「AI仮説」の区分であり、アイデアの優劣を示さない。

## 運用と検証
- 収集件数と関係の型の多様性、未探索領域、根拠の追跡可能性、重複率、例外の保持率を記録する。これらを選別の閾値にしない。
- 100方向探索を行う場合も同義語の水増しを避け、異なる機構・関係・分野を区別する。
- 無限自動探索はしない。人間が次の探索方向・回数・終了を決める。
- 研究目標は南方熊楠の一次資料を優先した300件。論考100、書簡・日記80、生物研究40、民俗・宗教50、関連研究30を目安とする。未検証の件数を調査済みと記載しない。
- 南方熊楠本人の明示的な方法、史料から推定した方法、PRINCIPLE LOOP 独自拡張を区別する。

## 他モジュールとの関係
岡田エンジン、赤瀬川スキャナー、林フィルター、秋元リアクター等とは必要に応じて人間が選択して組み合わせる。固定順序なし。PRINCIPLE LOOP の目標「再現性のある予想外の当たりを見つける」は不変。
