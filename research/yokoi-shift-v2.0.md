# YOKOI SHIFT v2.0 — 横井軍平の製品・発言からの研究更新

更新日: 2026-10-11
状態: 研究版（仮説と本人発言を区別）
位置付け: PRINCIPLE LOOPの独立選択式モジュール。常時実行・固定順序・他モジュールへの強制接続はしない。

## 中心原理
**前提を維持し、用途や関係を転換する。**（従来から維持）

追加の問い: **何を固定する必要がないかを見極める。**
目的は既存の性能競争で勝つことではなく、別の体験を成立させること。これは本人の言葉の逐語引用ではなく、研究からの独自要約。

## 本人の発言に基づく論点（一次資料・対談）
- 「新しい商品」と「最先端技術」は同義ではない。成熟した技術の使い方を変える視点。
- 携帯ゲームの画面サイズ、白黒液晶、電池寿命など、性能の最大化より体験・使い勝手・成立条件を優先する判断。
- 2画面の増設そのものではなく、画面間の遊びの接続が重要。
- 既存の光線銃を性能改善する競争より、新しい遊びの提案を志向。
- バーチャルボーイは新体験を狙ったが、受け手が従来機の基準で比較する問題も示した。

## 7つの独立選択式操作
1. **FIX**: 残すべき体験・機能を特定する。
2. **REMOVE**: 不要な常識・性能・操作を外す。
3. **TRANSFER**: 成熟した既存技術や機構を別用途へ移植する。
4. **RELATION**: 主役・脇役・操作主体・対象の関係を転換する。
5. **CONSTRAINT**: 制約を設計資源として使う。
6. **NEW FIELD**: 既存の競争軸を離れ、別の遊びを成立させる。
7. **DISCOVERY**: 実際の利用者が見つけた予想外の行動を次の試作の起点にする。

上記は横井本人が列挙した7項目ではなく、本人資料に基づく解釈とPRINCIPLE LOOP独自拡張を混ぜた操作群。必須の工程や成功パターンの量産テンプレートにはしない。

## 試作への適用例：『くものす おえかき』
観察: 大人が糸を描く一方、子どもはiPadを動かしててんとう虫を追った。
- FIX: iPadを動かす身体操作、対象の動きを追う体験
- REMOVE: 糸を描く操作の必須化
- TRANSFER: カメラを動かして追う仕組みを別の対象・現象へ
- RELATION: 観察者と観察対象の関係を逆転する可能性
- DISCOVERY: 予定外の遊びを独立作品の候補として扱う

これは実際の観察に基づく独自応用であり、横井本人の方法を直接再現したという主張ではない。

## 反証・評価
- 新しい体験でも、利用者が古いジャンルの評価軸で判断する場合がある。
- 変換だけで面白さが生まれるとは限らない。初回の理解、操作の因果、再挑戦の意欲を小さく検証する。
- 新規性、低コスト、遊びの成立を同一視しない。
- 成功事例だけでなくバーチャルボーイのような不成功事例を残す。
